How it works

1 · Send a link 🔗

YouTube, TikTok, Twitch, podcasts or a direct file. We fetch the captions automatically — or paste a transcript / upload the video.

2 · We find the moments 🎣

Every 15–60s window is scored on hook strength, emotion, pace, numbers, questions and curiosity gaps. The first 3 seconds of each clip are graded separately — that's what stops the scroll.

3 · You post the clips ✂️

Preview in place, copy the title / caption / hashtags, grab hook rewrites, and download a real 9:16 MP4 cut by ffmpeg.
